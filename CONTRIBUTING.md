# Contributing

Thanks for your interest in Table Focus.

This is a personal project that I maintain in my spare time. Bug reports and pull requests are welcome, but there is no guarantee of a reply, a fix or a merge. I may decline requests that do not fit the scope of the plugin (display-only, desktop-only).

## Bug reports

Open an issue and include:

- your Obsidian version and operating system,
- what you did, what you expected and what happened,
- a small Markdown table that reproduces the problem (please do not paste private notes).

## Feature requests

Open an issue and describe the problem you want to solve. Table Focus is intentionally small and display-only, so some requests may not be accepted.

## Pull requests

Please open an issue first so we can agree on the change before you write code. Small fixes are welcome.
